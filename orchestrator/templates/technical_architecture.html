Execution and recovery

Daily schedules use the relevant satellite’s local timezone. The master sends UTC period boundaries, and a retry keeps those same boundaries while creating a new attempt. A worker reports script status and logs; the collector determines whether its own work succeeded.

Capacity and fallback

A task is claimed by one eligible worker. Satellite capacity limits concurrent execution. Preferred and fallback routing can be configured per host; daily-local automatic fallback requires the same timezone. Running several workers is not a reason to execute the same task several times.
