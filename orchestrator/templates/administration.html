How discovery works


Connect a source, review its changes, then apply the preview. New hosts stay inactive until you activate them.



Inventory file format

Use a JSON or YAML file with this structure. You can also push it to POST /api/inventory/discover.


{"version":1,"hosts":[{"id":"example-host","zone":"EMEA","scope":"General","parameters":{}}]}


Configure zones first. New hosts are imported as Discovered / disabled. Missing hosts remain visible and are never removed automatically. Use scripts/sync_inventory.py to refresh the file from your API and trigger discovery.
